# Чистая нарезка

Сырое видео (один или несколько клипов) → чистый ролик без пауз и дублей → субтитры по словам. Это первый шаг монтажа: результат можно сразу публиковать или передать дальше в reels-motion-titles для заголовков.

Пользователь, скорее всего, не программист. Объясняй простыми словами, код не показывай. После каждого этапа: «что сделал» и «что проверить».

## Первый запуск (один раз на компьютер)
1. Скопируй папку `template/` из скилла в папку проекта пользователя.
2. Нужны Node.js 20+, ffmpeg, Google Chrome, Python 3.10–3.12. Чего нет — поставь (Mac: Homebrew, Chrome с google.com/chrome), спрашивая разрешения.
3. `npm install`.
4. `python3 -m venv .venv && .venv/bin/pip install sherpa-onnx numpy`.
5. Модель распознавания русской речи в `models/`: GitHub k2-fsa/sherpa-onnx → Releases → asr-models → `sherpa-onnx-zipformer-ru-2024-09-18.tar.bz2`, распаковать. Качай только с GitHub.
Всё бесплатно, интернет нужен только для установки.

## Как монтировать
1. **Исходник.** Клипы в `media/`. Посмотри один кадр (`ffmpeg -ss 2 -i клип -frames:v 1 work/look.jpg`): где человек по горизонтали — это `--x` (0.5 = центр). Вертикальная съёмка с телефона/камеры определяется сама.
2. **Слова.** Для каждого клипа: `.venv/bin/python scripts/transcribe.py media/клип.mp4 > work/клип.json` — номер, слово, начало и конец.
   **Казахский** (и другие языки): `.venv/bin/python scripts/transcribe_whisper.py media/клип.mp4 kk > work/клип.json` (нужен `pip install faster-whisper soundfile` в `.venv`; модель ~1.6 ГБ скачается при первом запуске). Распознавание казахского ошибается чаще — попроси у человека точный текст или сверяй по смыслу и спроси, если не уверен.
3. **Что оставить.** Прочитай слова и найди:
   - **дубли** — одна фраза сказана дважды; оставляй последнюю целую (сигналы: «ещё раз», «заново», «стоп», повтор начала фразы);
   - **оговорки и начала без конца** — «и… и тютор», обрыв на полуслове;
   - **мусор** — «э-э», «ну», «как бы» в начале фразы, разговоры до/после дубля («что, не знаю», «давайте»);
   - паузы искать не надо — они сжимаются сами (параметр `--gap`, по умолчанию 0.25 с).
   Покажи пользователю план: **оставляю** «текст» (номера слов), **вырезаю** «текст» — почему. Дождись «ок».
4. **Нарезка.** `python3 scripts/cut.py media/клип.mp4 work/клип.json --keep 26-44 --x 0.5` (несколько кусков — несколько `--keep` по порядку). Получится `work/cut.mp4`, `work/subs.json`, `work/cut.srt`.
   Несколько клипов: нарежь каждый в свою папку (`--out work/1`, `work/2`…), склей `cut.mp4` через ffmpeg concat, а `subs.json` объедини со сдвигом времени. Проще всего — сначала склеить клипы в один файл (`ffmpeg concat`), потом всё как для одного.
5. **Субтитры.** Поправь `work/subs.json`:
   - пиши слова так, как человек **реально сказал** (распознавание путает имена, города, бренды: «оматы» → «Алматы»), с заглавной в начале фразы и знаками вопроса/восклицания;
   - `"key": номер слова в субтитре` (с 0) — это слово в жёлтой плашке. Один ключ на 2–3 секунды: цифры, имена, главное слово фразы. `-1` — без плашки;
   - если в одном «слове» распознавание склеило два (`распяты` = «раз пятый») — так и пиши через пробел;
   - мат — звёздочки (`бл**`), звук запикать отдельно, если просят.
6. **Проверка.** `node render_subs.mjs still 1.5 4 6` → посмотри `work/still_*.png` сам: субтитр не закрывает лицо, не обрезан, плашка на нужном слове. Потом 2–3 кадра пользователю.
7. **Готово.** `node render_subs.mjs` → `out/готово.mp4` (громкость под Reels). Отдай также `work/cut.srt` — субтитры для CapCut/Premiere.

## Настройки
- Стиль субтитров — переменные в начале `subs.html`: `--top` (высота, по умолчанию 1320 из 1920), `--size`, цвета текста и плашки. Шрифт Montserrat (бесплатный, кириллица и казахские буквы).
- Субтитры закрывают лицо (человек низко в кадре) — подними `--top` до ~1500 или опусти до ~1150.
- Нужна лёгкая «подушка» между фразами — `--gap 0.35`; совсем плотно — `--gap 0.15`.
- Срезает конец слова — `--pad 0.12`.

## Правила
- Резать только то, что пользователь одобрил в плане.
- Смысл не меняем: не переставляем фразы и не склеиваем куски так, чтобы получилось то, чего человек не говорил.
- Субтитры — дословно, без «улучшений» текста.
- Перед удалением исходников всегда спрашивай; исходники не трогай вообще, вся работа — в `work/` и `out/`.

## Частые проблемы
- **Слово обрезано на стыке** — увеличь `--pad` или проверь номер слова в `--keep`.
- **Щелчок на склейке** — обычно исчезает с `--pad 0.1`; если нет, сдвинь кусок на соседнее слово.
- **Человек не по центру после кропа** — подбери `--x` (0.4 — левее, 0.6 — правее).
- **Субтитр раньше/позже голоса** — поправь время слова в `subs.json`.
- **«Не нашёл Google Chrome»** — установи Chrome.
