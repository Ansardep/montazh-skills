# Reels Motion Titles

Монтаж говорящей головы 9:16 кодом (Remotion). Человек присылает сырое видео → ты делаешь ролик, где каждый заголовок, плашка и субтитр появляются ровно на слове.

Пользователь, скорее всего, не программист. Объясняй простыми словами, код не показывай без просьбы. После каждого этапа: коротко «что сделал» и «что проверить».

## Первый запуск (один раз на компьютер)
1. Скопируй папку `template/` из этого скилла в папку проекта пользователя (например `my-reels/`).
2. Нужны Node.js 20+, ffmpeg, Python 3.10–3.12. Если чего-то нет — поставь сам (на Mac через Homebrew), спрашивая разрешения.
3. В проекте: `npm install`.
4. Python-пакеты в виртуальное окружение `.venv`: `sherpa-onnx numpy opencv-python pillow rembg onnxruntime`.
5. Модели в `models/` (скачивай с GitHub, не с HuggingFace):
   - `sherpa-onnx-zipformer-ru-2024-09-18` (k2-fsa/sherpa-onnx → releases → asr-models) — распознаёт русскую речь и даёт время каждого слова;
   - `yunet.onnx` — детектор лица из opencv/opencv_zoo (`models/face_detection_yunet/face_detection_yunet_2023mar.onnx`), переименовать в `models/yunet.onnx`.
6. Remotion при первом рендере сам скачает браузер.

## Как монтировать ролик
1. **Исходник.** Положи видео в `public/media/vNN.mp4`. Если не 1080×1920 — приведи ffmpeg-ом. Если есть вшитый чужой логотип — спроси, убирать ли (`delogo`).
2. **Слова и тайминги.** `.venv/bin/python scripts/words.py public/media/vNN.mp4 > src/wordsNN.ts`. Распознавание ошибается в именах и брендах — сверь с тем, что человек реально говорит (не с присланным текстом), исправь написание. Расставь `|` (новый субтитр) и `*` (ключевое слово в жёлтой плашке, 1 на 2–4 секунды).
3. **Сценарий графики.** Разбей речь на смысловые куски по 1.5–4 секунды. Для каждого: заголовок (2–4 слова), иногда курсив под ним, иногда плашки/карточки. Покажи план пользователю таблицей «секунда → что на экране» и дождись «ок».
4. **Код ролика.** Новый файл `src/ReelNN.tsx` по образцу `src/Example.tsx` + строка в `src/Root.tsx` (`durationInFrames` = секунды × 30). Все элементы — из `src/core.tsx`.
5. **Проверка кадров.** `node render.mjs stills ReelNN 1 4 8 ...` → посмотри PNG сам, найди наложения и обрезки, поправь. Потом покажи пользователю 3–4 ключевых кадра.
6. **Проверка лица (обязательно).** `node facecheck.mjs ReelNN 0.5` → `.venv/bin/python scripts/facecheck.py ReelNN public/media/vNN.mp4`. Должно быть `none`.
7. **Рендер.** `node render.mjs full ReelNN`, затем громкость под Reels:
   `ffmpeg -i out/ReelNN.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5 -c:a aac -b:a 192k -movflags +faststart out/ИМЯ.mp4`

## Элементы (src/core.tsx)
| Элемент | Что это | Когда |
|---|---|---|
| `Title` | Крупный узкий заголовок капсом, blur-in | Главная мысль куска, почти всегда |
| `Script` | Неоновый рукописный курсив, «пишется» слева направо | Уточнение под заголовком, эмоция. `kz` — для казахского |
| `Pill` | Стеклянная капсула, плавает, `strikeAt` зачёркивает | Перечисления, «было/стало», теги («1 НА 1») |
| `Card` | Скрин/фото вылетает сбоку и плавает | Показать продукт, интерфейс, результат |
| `Sticker` | Персонаж или 3D-объект выпрыгивает снизу | Акцент, юмор |
| `behind` в cfg | Огромное слово/цифра ЗА человеком | Цифры и удары: «30 МИНУТ», «2016». Нужен `scripts/cutout.py` |
| `Flash` | Вспышка цвета | Переход между частями |
| `Chevrons` | Стрелки вниз | Финальный CTA |
| `punch` в cfg | Мягкий зум камеры | На смене мысли |
| `sfx` в cfg | Звук анимации | На каждом появлении крупного элемента |

## Правила стиля (соблюдать всегда)
- **Никогда не закрывать лицо** — ни текстом, ни карточками, ни стикерами. Проверка лица перед каждой отправкой.
- **Безопасные зоны Reels:** ничего важного в 0–400 px сверху и 1560–1920 px снизу; по бокам ~10%. Заголовок ≤ 860 px, курсив ≤ 780, слово за головой ≤ 900 (`Fit` ужимает сам).
- Если голова в центре/вверху и заголовок её задевает — опусти текст вниз на одежду (`top` ~1180, субтитры ниже).
- Заголовок всегда **в одну строку**, 2–4 слова, без точек. Курсив сразу под заголовком, без большого зазора.
- **Чередуй цветовые пары** `PAIRS` 1–7, не держи одну пару весь ролик.
- **Всё строго под голос:** элемент появляется в момент, когда звучит его слово (время из words).
- Камера спокойная: зум не чаще раза в ~2.6 с.
- Звуки анимации всегда есть, но тише голоса (0.10–0.16). Музыка, если добавляешь, — ~0.065.
- Субтитры — по тому, что человек реально сказал. Мат — запикать, на экране звёздочки.
- Без дешёвых красных/зелёных плашек под текстом.
- Шрифты в шаблоне бесплатные (OFL). Если пользователь хочет свой шрифт — проверь, что он поддерживает кириллицу (и казахские буквы, если нужно), и что лицензия разрешает.

## Частые проблемы
- **Буквы другим шрифтом** — шрифт без кириллицы. Замени на шрифт с кириллицей.
- **Субтитр раньше/позже голоса** — поправь время слова в `wordsNN.ts`, проверь по звуку.
- **Распознавание путает слова** — исправь текст вручную, тайминг оставь.
- **Рендер долгий** — сначала всегда stills, полный рендер только после «ок».
