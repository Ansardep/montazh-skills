# Раскадровка референса «моушн на экране ноутбука» (104 с, 9:16, 30 fps)

## Что это за формат
- **Приём:** готовая моушн-графика (горизонтальная, 16:10) играет на экране **настоящего ноутбука**, ноутбук снят телефоном вертикально в тёмной комнате с фиолетовой подсветкой. Сверху в кадре — монитор, снизу — подсвеченная клавиатура. Камера почти статична, лёгкое дыхание руки.
- **Голос** — сгенерированный (ИИ-клон), и это сам по себе поворот сюжета на 28-й секунде.
- **Мета-приём:** ролик сам является доказательством. «Это сделано без After Effects» — и зритель смотрит на то, что сделано без After Effects.
- **Монтажных склеек всего одна** (8,9 с). Всё остальное — переходы внутри графики.

## Визуальный язык графики
| Элемент | Как выглядит |
|---|---|
| Фон | чёрный, тонкая белая сетка (иногда в перспективе — «пол» 3D-сцены) |
| Цвет | белый + неоново-фиолетовый (~#9B5CFF), сильное свечение (glow) |
| Ведущий объект | светящийся фиолетовый шар-курсор: «рисует» линии, приносит текст, из него вылетают элементы |
| Крупные слова | жирный гротеск капсом (типа Druk / Montserrat Black), белое слово + фиолетовое слово |
| Мелкий текст | обычный гротеск, появляется по словам; моношрифт для промптов и кода |
| UI-детали | тонкие рамки, уголки, HUD-подписи, таймер «01:30.00», REC, тайм-коды, плёнка, плеер |
| Переходы | RGB-глитч, смаз-вжух, вспышка в белый, распад на частицы/шум, разворот 3D-плоскости |
| Ритм | 1 фраза голоса = 1 сцена, смена каждые 2–4 с; ключевое слово — удар крупным капсом |

## Почему он цепляет
1. **Хук-спор с таймером** (01:30 на экране) — зритель досматривает, чтобы проверить.
2. **Два поворота-доказательства:** «голос сгенерирован» (0:28) и «всё это — код» (0:52).
3. **Чередование громко/тихо:** огромный капс → маленькое слово на чёрном.
4. **Каждое существительное визуализировано** — нет ни одной секунды «просто текста».
5. **Реальный ноутбук в кадре** даёт ощущение «живого», а не «нарисованного» ролика.

## Как я это применю к твоей озвучке
1. **Расшифровка по словам** (Whisper, тайм-код каждого слова).
2. **Сценарий сцен:** режу текст на фразы, каждой даю тип сцены из библиотеки ниже, ключевые слова — в удар капсом.
3. **Рендер графики кодом** (Remotion/HTML → MP4), всё синхронно со словами: появление, удары, звуки (вжух, бум, тики печати).
4. **Сборка — два варианта:**
   - **А. Как в референсе:** рендер 16:10 → ты включаешь его на ноутбуке на весь экран и снимаешь телефоном (штатив, тёмная комната, подсветка) → я накладываю твою озвучку на запись. Самый «живой» результат, без композитинга.
   - **Б. Без съёмки:** я сам вставляю графику в кадр ноутбука (нужно 10–15 с статичного видео твоего ноутбука) или делаю чистую вертикальную версию 9:16 на весь экран.
5. **Цвета/шрифт** — по твоему стилю (могу заменить фиолет на розовый).

### Библиотека сцен (что можно переиспользовать под любой текст)
- курсор-шар, пишущий фразу; удар капсом белый+цвет; тихое слово на чёрном
- таймер-обещание; схема блоков со стрелками и перечёркиванием
- поле ввода с печатающимся промптом; окно кода; окно аудиоволны
- киноплёнка → плеер; анкета/чекбоксы; словарная статья
- полноэкранная вспышка с чёрными словами; дуга «от A до Б»; счётчик цифр

### Что нужно от тебя
- файл озвучки (mp3/wav), язык (рус/каз)
- вариант сборки: А (снимешь ноутбук) или Б
- нужен ли живой хук с лицом в первые 2–3 секунды
