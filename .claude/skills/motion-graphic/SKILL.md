# Motion graphic — неон на экране ноутбука

Человек даёт текст (или озвучку) → ты пишешь сцены кодом в `video.html` (canvas) → рендер в mp4 со звуками на каждый эффект. Человек потом сам включает ролик на ноутбуке и снимает телефоном, голос накладывает сам (или голос уже внутри, если дал озвучку).

Пользователь, скорее всего, не программист. Объясняй простыми словами, код не показывай без просьбы. Разбор референса, на котором построен стиль: `reference/раскадровка.md`.

## Первый запуск (один раз)
1. Скопируй `template/` из скилла в папку проекта (например `рилс идеи/<название>-моушн`).
2. Нужны Node.js 20+, ffmpeg, Google Chrome. Если нет — поставь, спрашивая разрешения.
3. В проекте: `npm install`.
4. Звуки уже лежат в `a/sfx/`. Пересоздать/подкрутить: `python -I scripts/sfx.py` (нужен numpy).
5. Для тайминга по озвучке: `pip install faster-whisper numpy`.

## Как собрать ролик
1. **Текст.** Обычно ~30 с, 60–90 слов, смесь казахского и русского — это нормально, не переводи.
2. **Тайминг.**
   - Есть озвучка → положи в `media/voice.mp3`, `python -I scripts/words.py media/voice.mp3 media/words.json`, расставь времена сцен и слов по `words.json` (распознавание путает имена/английские слова — сверяй с текстом). Голос попадёт в ролик сам.
   - Нет озвучки → оцени темп (~2.5–3 слова/с) и честно скажи пользователю, что тайминг на глаз и подгоняется под запись за пару минут.
3. **План сцен.** Одна фраза = одна сцена, 1.3–4.5 с. Покажи таблицу «секунды → фраза → что на экране» и дождись «ок». Ритм: удар капсом → тихая пауза (мелкое слово на чёрном) → схема/предмет → удар. Каждое существительное — картинкой.
4. **Код.** Перепиши блок «СЦЕНЫ» в `video.html` (там готовый пример на 11 сцен — бери его приёмы). Остальное (утилиты, фон, HUD, компоновка) не трогай без нужды.
5. **Кадры.** `node render.mjs stills 2.6 5 9.9 ...` — по кадру из середины каждой сцены и из середины анимаций; смотри `frames/still_*.jpg` сам. Ищи наложения текста, обрезки по краям, пустые сцены. Склей сетку через ffmpeg xstack и посмотри разом.
6. **Рендер.** `node render.mjs full` → `out/video.mp4` (~1 минута на 30 с ролика). Скопируй результат рядом с проектом с понятным именем и отправь пользователю.
7. **Варианты CTA.** Текст кнопки в конце меняется без правки кода: PowerShell `$env:CTA='CLAUDE сөзін жаз'; node render.mjs full` (bash: `CTA='...' node render.mjs full`). По умолчанию «СІЛТЕМЕНІ БАС». Кнопка растягивается под текст.

## Инструменты в video.html
| Функция | Что делает |
|---|---|
| `scene(a, b, (c,t)=>{...}, {noHud, softIn, softOut})` | Сцена с a по b секунду ролика (время t — абсолютное). Переходы сами: глитч-срезы на входе, размытие на выходе. `softIn`/`softOut` — мягкое растворение без глитча (перед финалом). `noHud` — без рамки/таймера (для полноэкранных вспышек) |
| `slam(c,t,t0,'СЛОВО',x,y,size,col,align)` | Удар капсом: буквы вылетают по очереди, пружинят как желе. Цвет `'#fff'`, `A` (акцент) или тёмный для светлого фона |
| `words(c,t,[[t0,'слово',цвет?],...],x,y,size,weight,align)` | Субтитры по словам, каждое пружинит. Раскладка заранее — ничего не прыгает. Возвращает x конца строки |
| `typed(c,t,t0,cps,'текст',x,y,size)` | Печать по буквам (каждая буква пружинит). Возвращает x каретки — туда ставь `orb` |
| `jellyPiece(...)`, `jel(tau)`, `wob(tau)` | Пружина и сплющивание — используй для любых появлений (иконки, плюсы, карточки, кнопки) вместо линейных |
| `orb(c,x,y,r)` | Светящийся шар-курсор |
| `line`, `rr`, `brackets`, `mono`, `text` | Линии со свечением, скруглённые рамки, уголки, моношрифт для HUD |
| `sfx(t,'имя',громкость)` | Звук на секунде t. Звуки: `whoosh`, `whoosh_out`, `swish`, `boom`, `hit`, `glitch`, `tick`, `click`, `pop`, `ding`, `draw`, `beep`, `riser`, `flash`, `drone` (фон). `regWords(list)` / `regTyped(...)` — звуки на каждое слово/букву |

Правило: **у каждого появления есть звук.** Удар капсом → `hit`/`boom`; слово → тихий `swish` (0.2); буква → `tick`; линия рисуется → `draw`; карточка → `whoosh` + `pop`; галочка → `ding`; смена сцены → `glitch`/`whoosh_out`.

## Стиль (что пользователь уже утвердил)
- Акцент розовый `#ff3ea5` (`const A`), белый текст, фон `#05040a` с сеткой 80 px. Шрифт Inter (есть казахские буквы Ә Ғ Қ Ң Ө Ұ Ү Һ І): 900 — удары, 300 — тихий текст.
- Текст **мягкий, желейный**, не «деревянный» — все появления через пружину, без линейных fade.
- **Без белых вспышек и резкого нарастающего вжуха перед финальной кнопкой** — туда только плавное растворение (`softOut`/`softIn`).
- Таймер-обещание в правом верхнем углу отсчитывает 30 → 0 к моменту кнопки.
- Размер 1920×1200 (MacBook 16:10). Под другой экран — поменяй `W/H` в `video.html` и viewport в `render.mjs`.

## Если что-то не так
- На Windows рендер в несколько вкладок Chrome зависает — в `render.mjs` стоит `PAGES = 1`, не повышай.
- Буквы налезают на соседние во время пружины → уменьши `kx` (горизонтальный размах) в вызове `jellyPiece`.
