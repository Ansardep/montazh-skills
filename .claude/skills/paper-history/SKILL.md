# Бумажная история

Адаптация открытого движка **papercut** (MIT, автор Bashar Mokdad, github.com/basharmokdad/papercut) для русского и казахского языка. Что изменено — в `АВТОРСТВО.md`.

Одна тема → готовый ролик 9:16. Картинки — настоящие архивные фото из Wikimedia Commons (только общественное достояние и CC0), движок сам вырезает, печатает точками на бумаге и оживляет по кусочку.

Пользователь, скорее всего, не программист. Объясняй простыми словами, код не показывай. Останавливайся там, где написано «Стоп».

Пути (относительно папки этого скилла, где лежит SKILL.md):
- движок: `<скилл>/engine/papercut.py`
- python: `<скилл>/.venv/bin/python` (Mac/Linux) или `<скилл>/.venv/Scripts/python.exe` (Windows) — создаётся установкой

Один ролик = одна папка, все команды запускай из неё: `"<python>" "<скилл>/engine/papercut.py" make story.json`.

## Первый запуск (один раз)
Нужны Python 3.10+, Node 18+, ffmpeg, git (поставь, спрашивая разрешения). Затем в папке скилла: `bash setup.sh` (Windows: `powershell -ExecutionPolicy Bypass -File setup.ps1`). Установка создаёт `.venv`, ставит библиотеки и скачивает карты и анимацию. Около 10 минут, всё бесплатно.

## Порядок работы

### 1. Факты
Найди тему в интернете. Каждую дату, имя и цифру — минимум по двум независимым источникам. Источники расходятся — пиши обтекаемо («в 1910-х», а не точный день). Цитаты не выдумывай: только документальные слова или никаких.

### 2. Текст
- 10–14 сцен (beats), 30–45 секунд. Одна фраза — одна сцена — одна картинка.
- Короткие спокойные предложения, как в документальном кино. Цифры пиши так, как их произносят, если голос будет из ElevenLabs («тысяча девятьсот двенадцатый»).
- Без ИИ-штампов. Последняя фраза короткая и запоминается.
**Стоп.** Покажи текст и дождись «ок».

### 3. Голос
- **Своя запись:** человек читает текст целиком на телефон, без длинных пауз → файл в `media/voice.mp3` (или .m4a/.wav). Бесплатно.
- **ElevenLabs:** если у человека есть аккаунт — озвучь текст и сохрани в `media/voice.mp3`. Предупреди, что тратятся его кредиты.
Текст в `story.json` должен совпадать с тем, что реально сказано: движок раскладывает его на голос по буквам. Человек оговорился или переставил слова — поправь `say`.

### 4. Картинки
```
"<python>" "<скилл>/engine/papercut.py" search "Almaty 1912" sheet.png
```
Ищи по-английски (так больше результатов). Открой `sheet.png` и выбирай глазами, не по названию.
- **Люди:** `"cut": true` (фон убирается). Лицо хорошо освещено и крупное. Тёмные и пёстрые фото режутся плохо — кадрируй (`"crop": [л, в, п, н]` в долях) или `"cut": false`.
- **Здания, улицы, комнаты, техника на фоне:** `"cut": false` — фото «на скотче».
- **Документы и почерк:** `"cut": false, "dots": false`.
- **Свои картинки или талисман** (например Клоуди): `"file": "sources/имя.png"`.
- Никогда не подписывай фото не тем предметом. Нет настоящего фото — используй сцену `document`, `number` или `timeline`.
- Wikimedia иногда отвечает «слишком много запросов» — подожди минуту и запусти снова.

### 5. story.json
```json
{
  "title": "Каким был Верный", "slug": "verny", "format": "9:16",
  "voice": "file:media/voice.mp3", "language": "ru", "music": "bed", "seed": 7,
  "images": {
    "almaty": {"commons": "File:Almaty 1912.jpg", "cut": false, "accent": "teal"},
    "cloudy": {"file": "sources/cloudy.png", "cut": true, "dots": false}
  },
  "beats": [
    {"say": "Тысяча девятьсот двенадцатый год. Город Верный.", "kind": "photo", "bg": "mustard", "photo": "almaty", "label": "ВЕРНЫЙ | 1912"}
  ]
}
```
`language`: `ru` или `kk` (казахский; распознаётся хуже — проверяй время слов). Голос по-английски встроенный: убери `voice` и `language` (нужна модель Kokoro, см. «Английский голос»).

Картинки: `commons` (точное имя `File:…`) или `file` (свой файл), `cut`, `dots`, `crop`, `accent` (red, mustard, teal, null), `size`, `contrast`.

Виды сцен (у всех ещё есть `bg`, `scraps`, `burst`, `transition`):

| kind | поля | для чего |
|---|---|---|
| `hero` | `hero`, `label`, `tag`, `stamp`, `stamp_on`, `circle` | человек или предмет крупно |
| `photo` | `photo`, `label`, `tag`, `stamp`, `stamp_on` | улица, здание, сцена |
| `duo` | `left`, `right`, `string`, `label` | двое и связь между ними |
| `number` | `number`, `sub`, `stamp`, `hero` | дата, сумма, количество |
| `document` | `head`, `lines`, `redact`, `mark`, `stamp`, `hero`, `label` | машинописный текст, список |
| `timeline` | `dates`, `active`, `hero`, `label` | до/после, отрезок лет |
| `quote` | `quote`, `by`, `hero` | настоящая цитата с источником |
| `map` | `map: {country или highlight[], pin: [долгота, широта], place, sea}`, `label`, `stamp` | где это было (`country` по-английски: "Kazakhstan") |

`bg`: mustard, red, teal, navy, newsprint, kraft, cream, pink, olive, ink. Чередуй тёплые и холодные, два одинаковых подряд нельзя.
`stamp_on`: слово из `say`, на нём падает печать.
Подписи (`label`, `stamp`): 1–3 слова, капсом. `label_size` уменьшает длинные, `|` — перенос строки.
Шрифты в движке с кириллицей и казахскими буквами: плакатный (Oswald), машинка (PT Mono), жирный для субтитров (Montserrat Black), маркер (Caveat).

### 6. Сборка, проверка, рендер
```
"<python>" "<скилл>/engine/papercut.py" make story.json
```
1. Открой `pieces.jpg`: все вырезки на одном листе. Клякса или нет лица — перекадрируй, подними `contrast` или `cut: false`.
2. `"<python>" "<скилл>/engine/papercut.py" snap story.json 2.1,5.4,...` — по кадру ближе к концу каждой сцены (время сцен в `project/assets/audio/timing.json`). Проверь: ничего не вылезает за край, важное не под субтитрами, печати читаются, русские буквы на месте.
3. Поправь `story.json`, снова `make` (вырезки и голос кэшируются).
4. `"<python>" "<скилл>/engine/papercut.py" make story.json --render` → `<slug>.mp4` (1080×1920, 30 к/с, громкость под Reels).
**Стоп** перед рендером: покажи 3–4 кадра пользователю.

Авторы всех фото записываются в `CREDITS.txt` — их нужно вставить в описание ролика.
