# Разбор стиля «Окна в комнате»

Источник приёмов: обучающее YouTube-видео про Claude Code (16:29, 16:9, ~55 тыс. просмотров за 2 недели, в 4,6 раза выше обычного для канала). Ниже — что именно сделано в монтаже и как это перенесено в скилл. Копируем приёмы, не контент.

## Кадр и съёмка
- 16:9, одна неподвижная камера, средний план. Спикер сидит на терракотовом диване **правее центра**; слева — «пустая» часть комнаты: деревянная лестница, кухня, картина, окна в пол.
- Свет мягкий, тёплый, слева; фон слегка размыт. Грейд тёплый: кремовые, терракота, приглушённый синий, мягкие чёрные.
- Именно пустая половина комнаты — «экран» для графики. Поэтому при съёмке под этот стиль: садиться на правую треть, оставлять слева пустое пространство с интересными предметами.

## Темп
- Новое событие каждые 1,5–3 с: окно, вставка, приближение, плашка.
- Приближения цифровые и жёсткие (с ~100 % до ~120–140 %), без плавного наезда, на сильных фразах.
- Паузы вырезаны почти до нуля, голос идёт сплошным потоком. Субтитров нет.

## Хук (0:00–0:55)
1. 0:00–0:05 — обещание в камеру: «дай мне 20 минут — и получишь …».
2. 0:06–0:37 — «машина доказательств», каждая 2–4 с: счётчик денег на чёрном (крутится до «600 000 ₽»), сетка из 35+ автоматизаций с переключателями, окно монтажной программы в комнате, «2 800 рилсов» над стеной из миниатюр и рядом иконок соцсетей, личный кабинет объявлений со счётчиком «2 900 000 ₽», и т. д.
3. 0:38–0:53 — карта ролика: цифры 1, 2, 3 с подписями «первый день / средний уровень / продвинутый» стоят **прямо на ступенях лестницы** за спиной спикера.

## Графика
- **Окна в комнате:** тёмные окна в стиле macOS (три точки, заголовок по центру) висят в левой части кадра рядом со спикером: проводник с папкой, загрузка программы, файлы, терминал, граф связей заметок. Мягкая тень, иногда лёгкая перспектива. Появление — масштаб 85→100 % с размытием, уход — размытие.
- **Полноэкранные тёмные вставки:** почти чёрный фон с мягким светом в центре, огромные белые жирные цифры (геометрический гротеск, плотный кернинг), маленькая серая подпись под ними. Цифры «прокручиваются» с размытием движения.
- **Записи экрана на весь кадр:** тёмный интерфейс, окна, док с иконками; в углу плашка главы.
- **Главы:** хромовая/металлическая объёмная цифра на тёмном («2»), затем плашка в левом верхнем углу «[2] Железное правило», висит всю главу. Для уровней — плашка с иконкой-столбиками «ступень 3» и гигантское слово («ПРОДВИНУТЫЙ») в пустой части комнаты.
- **Нумерованные ошибки:** плашка «Ошибка №1» в углу окна.
- **Диаграммы:** карта занятого места на диске (прямоугольники), шкала лимитов, граф связей (точки и линии).
- **Уведомления:** пилюли-уведомления стопкой с задержкой ~0,15–0,5 с.
- Палитра: фон #0b0b0d…#141416, текст #ffffff / серый #9ca3af, акцент терракота #E26D46, зелёный #22C55E для успеха и кнопок, моно-шрифт для кода.

## Звук
- Тихий электронный/лоу-фай бит под голосом, сильно приглушён во время речи, чуть громче на полноэкранных вставках.
- Вжух на каждое окно и переход, поп/тик на плашки и переключатели, клавиатура на печать, низкий удар на главах и больших цифрах.

## Реклама
- «Зерно» в середине (около 12:00) — упоминание в контексте задачи.
- Основной блок в конце (15:48–16:24): телефон с приложением клуба на чёрном, лендинг с крупным заголовком и зелёной кнопкой с ценой, прямой призыв.

## Концовка
- Тизер следующего видео окном-превью и «погнали» — конец через полсекунды после последнего слова, без заставок.

## Конкретные числа (для плана)
| Параметр | Значение |
|---|---|
| Событие на экране | каждые 1,5–3 с |
| Приближение | ×1,25–1,4, жёстко, 1 раз в 15–30 с |
| Пауза в речи | ≤ 0,15 с |
| Появление окна | 0,5–0,6 с, масштаб 85→100 %, размытие 18→0 px |
| Счётчик | 0,7–1 с, размытие движения |
| Глава (хром) | 1,5–2,5 с + удар басом |
| Скругление окон | 14 px, тень 40–90 px |
| Текст в окне | ≤ 5–6 строк, моно для кода |
| Уведомления стопкой | шаг 0,4–0,5 с |
| Реклама в конце | 20–40 с |
