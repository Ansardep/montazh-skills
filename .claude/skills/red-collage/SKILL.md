# Красный коллаж

Ролик без лица 9:16 кодом: голос за кадром → сцены в HTML → рендер в mp4 с голосом, звуками и музыкой. Всё бесплатно, на компьютере.

Пользователь, скорее всего, не программист. Объясняй простыми словами, код не показывай без просьбы. Останавливайся там, где написано «Стоп».

## Первый запуск (один раз на проект)
1. Скопируй папку `template/` из скилла в папку проекта (например `МОИ РИЛСЫ/reels/<тема>/`).
2. Нужны Node.js 20+, ffmpeg, Google Chrome, Python 3.10+ с `faster-whisper numpy pillow` (на Mac команда — `python3`, на Windows — `python`). Для удаления фона с фото — `pip install rembg` (без него работают только PNG без фона). Чего нет — поставь, спрашивая разрешения.
3. В проекте: `npm install`.
4. Звуки (`a/sfx/`) и музыка (`a/music/drone.wav`) уже лежат в шаблоне, синтезированы кодом (`scripts/make_sfx.py`) — чужих сэмплов нет.

## Как собрать ролик

### 1. Текст
Структура, которая держит (проверено на референсе):
- **Хук-парадокс в первую секунду**: «Что если X никогда не было проблемой?». Голос с 0,0 с, без вступлений.
- **Второй визуальный хук на 2–3 с** — шок-картинка (лицо пополам, череп, удар).
- 6–9 коротких фраз, 20–35 с, 2,5–3 слова в секунду. Каждое существительное — то, что можно показать.
- **Пауза-перелом** примерно на 2/3 (провал в тоннель) и вывод, который закольцовывает начало.
- Последняя фраза короткая. По желанию — CTA.
Без ИИ-штампов. **Стоп.** Покажи текст и дождись «ок».

### 2. Голос → `media/voice.mp3` (или .wav/.m4a)
Своя запись на телефон или ElevenLabs. Низкий спокойный «документальный» голос подходит лучше всего.
Затем: `python scripts/words.py media/voice.mp3 ru > media/words.json` (`en`, `kk` — другие языки). Сверь слова с текстом — имена и английские слова распознаются с ошибками; время важнее написания.

### 3. Картинки → `a/img/`
`python scripts/cut.py media/фото.jpg a/img/имя.png --mode dots|photo|clean [--crop л,в,п,н] [--keep-bg]`
- **dots** — ч/б газетные точки: «гравюры» лиц, черепа, предметы (помада, деньги, часы, микроскоп). Главный приём стиля.
- **photo** — приглушённое ч/б фото: главное «живое» лицо, которое держит ролик.
- **clean** — без обработки: логотипы, свои картинки.
- Люди — только голова с волосами (кадрируй `--crop` до плеч), лицо крупно и хорошо освещено.
- Фото берёт пользователь (свои, стоки с лицензией, генерация) или Wikimedia Commons (общественное достояние). Чужих реальных людей и чужие бренды — только если пользователь сам о них говорит.
- Открой каждую вырезку и проверь глазами: нет ли клякс, обрезанного лица.

### 4. План сцен
Одна фраза = одна сцена (0,8–3,5 с). Для каждой: время, текст, главная картинка, приём, звук. Покажи таблицей и дождись «ок» (**Стоп**). Правила темпа:
- смена картинки каждые ~1 с, ни одна сцена не стоит дольше 3,5 с;
- предмет появляется **на слове, которое его называет**;
- удар (`data-hit`) — на шоковое слово, 1 раз в 2–4 с, не чаще;
- инверт/глитч — 1 раз за ролик, тоннель — 1 раз, на переломе.

### 5. Код
Пиши сцены в `video.html` (там готовый пример на 9 сцен — замени его). `style.css` и `engine.js` не меняй без нужды.

### 6. Проверка
- `node render.mjs sheet 0.5` → `frames/sheet.jpg`: весь ролик одним листом. Смотри сам: обрезки, наложения текста на лицо, пустые кадры, текст не по голосу.
- `node render.mjs stills 1.2 4.5 ...` — отдельные кадры крупно.
- Исправь, потом **Стоп**: покажи пользователю 3–4 кадра.

### 7. Рендер
`node render.mjs full` → `out/video.mp4` (1080×1920, 30 к/с, голос + звуки + дрон с автоприглушением под голос, громкость под Reels). Своя музыка: положи `media/music.mp3` — заменит дрон. Быстрая проверка начала: `node render.mjs full 8`.

## Как устроен video.html
```html
<section class="scene" data-s="3.3" data-e="6.2" data-tr="flash" data-hit="1.12" data-bg="red">
  <div class="split" data-in="1.12"><img src="a/img/face.png"><img src="a/img/skull.png"></div>
  <div class="cap" data-w="0.06 1.12 1.4" style="top:1260px">Проблема | *страх* _ошибиться_</div>
</section>
<script src="engine.js"></script>
```
- `data-s` / `data-e` — начало и конец сцены в секундах ролика (из `words.json`). Сцены встык, жёсткая склейка.
- **Все остальные времена — от начала сцены** (секунда слова минус `data-s`).

### Сцена
| Атрибут | Что делает |
|---|---|
| `data-bg` | `red` (по умолчанию), `deep`, `black`, `paper`; `data-img="media/x.jpg"` — своё фото фоном (ч/б, размыто, красный тон) |
| `data-tr` | вход: `cut` (толчок камеры, по умолч.), `flash` (белая вспышка), `invert` (негатив 4 кадра), `glitch`, `zoom` (влёт с размытием), `fade` |
| `data-end` | выход: `tunnel` (провал в тёмную дыру), `black` (затемнение) |
| `data-hit="1.1 2.4"` | удар: бум + толчок + тряска |
| `data-shake="…"` | только тряска |
| `data-glitch="1.8-2.6"` | глитч в отрезке: RGB-сдвиг, сканлайны, дрожь |
| `data-cam` | `out` (отъезд), `none`, или `"1,1.15"` (своя сила наезда) |
| `data-sfx` / `data-vol` | звук на входе сцены вместо стандартного (`none` — без звука) |

### Элементы
| Элемент | Что это | Ключевые атрибуты |
|---|---|---|
| `.cap` | текст по словам. `\|` — новая строка, `*слова*` — красным, `_слова_` — мелко | `data-w` (время каждого слова), `data-out`; классы `big`, `huge`, `small`, `dim`, `left`, `right`, `mirror`; `style="top:..px"` |
| `.cap.cloud` | слова «облаком» вокруг лица (хук) | `data-cx/cy/rx/ry` или `data-pos="x,y,размер …"` |
| `img.cut` | вырезка | `.face` — лицо по центру; `.glow` — со свечением |
| `.split` | лицо пополам: вторая картинка въезжает правой половиной | `data-in`, `data-gap` (ширина трещины) |
| `.flip` | флеш-нарезка картинок | `data-t="0 0.3 0.55 …"` — когда каждая |
| `.ribbon` | красная волна-лента проезжает по кадру, внутри — свои элементы | `data-in`, `data-dur`, `data-out`, `data-rot`, `style="top:…"` |
| `svg.marks` | красный пунктир рисуется (разметка морщин, стрелки) | `<path d="…">` внутри, координаты кадра 1080×1920; `data-in`, `data-step`; `class="solid"` — сплошная |
| `svg.chalk` | мел: `data-shape="ellipse"`, `ellipse-arrow`, `underline`, `strike`, `x`; `.red` | `data-in`, `style="left;top;width;height"` вокруг слова |
| `.crosses` | кресты и решётки по краям (`.red`) | `data-in`, `data-n`, `data-seed` |
| `.count` | счётчик (годы, суммы) | `data-from`, `data-to`, `data-in`, `data-dur`, `data-pre`, `data-post` |
| `.orbit` | предметы по кругу (монеты, иконки) | `data-r`, `data-ry`, `data-spin`, `data-step`, `data-sfx="coin"` |
| `.scatter` | буквы слова разлетаются (`data-mode="in"` — слетаются) | `data-in`, `data-dur` |
| `.beam` | луч света | `data-in data-from="grow"` |
| `.clock` | циферблат с бегущими стрелками | `data-speed`, `data-tick` (тиканье) |
| `.tag` | мелкая подпись в углу («2026», «CREAMS») | — |
| `.badge` | плашка-иконка для CTA | — |

**Движение любого элемента:** `data-in="сек"`, `data-from="left|right|top|bottom|tl|tr|bl|br|scale|slam|grow|fade"` (диагонали — с поворотом, как влёт вырезок), `data-pop` (пружинка), `data-dur`, `data-dist`, `data-out`, `data-zoom="1,1.1"` (медленный наезд), `data-float`, `data-drift="dx,dy"`, `data-spin`, `data-rot`, `data-pulse="72"` (сердцебиение).
**Звук элемента:** `data-sfx` + `data-vol`. Есть: `boom impact whoosh swish paper tick coin glitch flash riser type suck heart`.

## Звук (движок ставит сам)
| Что | Звук |
|---|---|
| склейка сцены | swish (flash/invert → flash, zoom → whoosh) |
| `data-hit` | boom |
| `.split` | impact |
| влёт по диагонали/сбоку | swish |
| `.flip` | paper на каждую смену |
| мел, кресты | paper |
| счётчик | tick |
| глитч | glitch |
| тоннель | suck |
| музыка | дрон, автоприглушение под голос |
Добавляй руками: coin на монеты, heart на сердце, riser перед кульминацией, tick на часы.

## Правила стиля (соблюдать всегда)
- **Всё строго под голос.** Слово появляется, когда звучит. Предмет — на слове, которое его называет.
- **Одна мысль — одна главная картинка по центру** (лицо или предмет, ~50 % ширины). Мелочь вокруг — не больше 3–6.
- **Текст не на глазах.** Крупно — под лицом (top 1150–1350), мелкие слова — облаком вокруг головы.
- **Цвет:** только бордовый, ч/б, кремовый текст и один красный акцент. Никаких других цветов.
- **Безопасные зоны Reels:** важное не выше 220 px и не ниже 1600 px, по бокам 60 px.
- Длинные строки уменьшаются сами, но лучше 1–3 слова в строке у `big`.
- Своё содержание, свои тексты. Референсы — только приёмы и темп, не перерисовывать чужой ролик кадр в кадр. Чужие логотипы — только если ролик о них.

## Частые проблемы
- **Слово не появляется** — в `data-w` меньше чисел, чем слов (`|` не считается, `*` и `_` не мешают).
- **Текст раньше/позже голоса** — поправь число в `data-w` (время от начала сцены!).
- **Красный пунктир не там** — координаты `path` в пикселях кадра 1080×1920; сначала сделай кадр `stills`, потом подгони.
- **Буквы не тем шрифтом** — Playfair Display грузится из Google Fonts, нужен интернет при рендере; без него будет Georgia.
- **«Нужен rembg»** — `pip install rembg`, или дай PNG без фона, или `--keep-bg`.
- **Рендер не запускается, «Не нашёл Google Chrome»** — установи Chrome.
