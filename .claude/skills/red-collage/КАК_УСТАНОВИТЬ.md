# Красный коллаж — установка

Скилл уже лежит в `~/.claude/skills/red-collage/` и подхватывается Claude сам.

Что нужно на компьютере (один раз):
1. **Node.js 20+** — nodejs.org
2. **ffmpeg** — `winget install Gyan.FFmpeg`
3. **Google Chrome** — google.com/chrome
4. **Python 3.10+** и библиотеки: `pip install faster-whisper numpy pillow`
5. По желанию, для удаления фона с фото: `pip install rembg`

Первый ролик: скажи Claude «сделай рилс в стиле красный коллаж про …» — он скопирует шаблон в папку проекта, поставит `npm install` и проведёт по шагам.

Как пересоздать звуки и музыку (если захочешь поменять): `python scripts/make_sfx.py` в папке шаблона.
